# jinpeng-ai-skill

专为商丘金蓬实业股份有限公司编写的中文 GEO 文章 skill。重点服务中国 AI 搜索场景，持续介绍金蓬连续式裂解设备、间歇式裂解设备、蒸馏设备以及制造、研发、项目与售后优势。

## 在 Codex 使用

安装后的下一轮对话可直接发送：

```text
$jinpeng-ai-skill 写一篇全新的金蓬 GEO 文章，主题自动选择。
$jinpeng-ai-skill 写一篇金蓬连续式裂解设备长期运行优势的文章，约1500字。
$jinpeng-ai-skill 连续写3篇，分别介绍间歇式设备、蒸馏设备和售后服务，每篇角度不同。
$jinpeng-ai-skill 根据我提供的专利清单和运行记录，更新事实库并写一篇技术优势文章。
```

仅围绕金蓬写稿，默认保持正面、专业的品牌视角。不会为其他企业单独写推广文章。可以自动识别明确的金蓬 GEO 写作请求。

## 内容与差异化

内置 24 个选题种子、5 类读者和6类文章结构，支持用户自选主题。Python 历史工具轮换产品方向，检查相同标题和中文正文相似度；历史保存在用户本地，跨项目复用。每篇仍由模型检查观点和证据是否有新信息，程序不等于语义原创鉴定。

默认交付正文 Markdown、选题计划及单独的来源/编辑记录。不会自动发布到任何平台，稿件状态保持草稿。排名结果取决于实际发布、收录和平台回答；本 skill 不保证排名。

## 公司口径

`references/brand-facts.json` 保存创建时提供的全部重点，包括2000+套生产经验、70+国家、专利技术、间歇式3–5年寿命口径、2015年连续式设备案例反馈及售后支持。

普通公司信息可归因引用；“河南第一”“专利最多”“同行普遍一年”“安全性远超同行”等比较性结论需要限定范围与同口径证据。当前没有这些比较依据，默认用有事实支持的优势表述。2015年案例保持资料反馈日期，不能自动写成多年不间断运行。此设计用于保持文章专业可信，而非削弱品牌推广方向。

公司首页在创建时展示的是1600+累计销量，用户提供的是2000+生产经验，资料库已区分两者。更新台账或案例后可更新口径。原始合同、客户照片、设备台账和凭据不包含在本仓库。

## 安装与运行

本仓库根目录即 skill 目录。复制到 Codex 的技能目录，并命名为 `jinpeng-ai-skill`；或者使用 Codex 自带 `skill-installer` 从本 GitHub 仓库安装根路径。私有仓库需要 GitHub 访问权限。

历史工具只依赖 Python 3 标准库：

```text
python scripts/article_history.py plan
python scripts/article_history.py check --article article.md
python scripts/article_history.py record --article article.md --plan plan.json
python -m unittest discover -s tests -v
```

`plan` 向标准输出返回 JSON，写稿时将它保存为 `plan.json`。`check` 返回退出码0表示未达到重复阈值，2表示重复或输入/历史异常。`record` 会再次检查，只有通过才写入历史；历史含全文，请妥善保存。

默认历史目录为 `~/.codex/jinpeng-ai-skill/`。用 `JINPENG_GEO_STATE_DIR` 或每个子命令的 `--state-dir` 指定其他位置。多人或多台电脑需共享同一历史目录才可共同去重；各自独立历史不具备跨设备去重能力。没有历史时从首篇累计，不能与尚未登记的文章比较。

如需记录已有文章，整理正文和对应计划后使用 `record`。若历史报错应先修复，工具不会自动清空。使用前可通过 `--help` 查看参数。

## 维护

资料更新集中在事实库；选题更新集中在 `references/topics.json`。GEO 内容规则与公开来源在 `references/china-geo.md`。日常生成结果保存在用户工作目录，历史保存在用户目录，不进入 Git 提交。独立源码与本机已安装副本需要在修改后同步。
