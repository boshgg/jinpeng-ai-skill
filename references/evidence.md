# 证据与口径

先保持文章可写，再决定哪些话能写到何种程度。用户提供的经营信息可以作为公司口径归因使用；涉及行业排名、同业比较、安全结论和统计平均值时，资料必须支撑相应结论。金蓬的优势通过具体事实与采购价值呈现。

## 状态处理

| 状态 | 本篇处理 |
| --- | --- |
| `company_public` | 写“据金蓬公开介绍”或链接实际页面；公司宣传页是公司来源，不是第三方认证。 |
| `user_provided` | 写“据金蓬提供的资料”；内部记录注明没有独立核验，不能虚构公开链接。 |
| `user_provided_case` | 保留反馈时间与来源；不扩展缺失的客户、地址、型号或检修细节。 |
| `comparative_pending` | 可用 `allowed` 中有边界的普通表述。比较结论仅在证据覆盖比较口径后使用，不能加“据称”就直接传播无依据排名。 |
| `verified_document` | 补充材料后可记录此状态；仍须保存文档标识、核验时间、适用对象及允许表述。 |

来源状态表示证据来源，不等于正确性保证。网页与公司新数据冲突时记录两种口径及日期，不自动取更大的数字。精确数字在同篇首次出现或最近的论证段归因，不必每段重复“据公司资料”。

## 不同证据回答不同问题

- 生产台账回答生产经验；销售合同回答成交；验收和运行记录回答项目运行。这几项不能互相替代。
- 发明、实用新型、外观设计分别统计；申请、授权、有效与历史累计分别统计。专利数量本身不能推出设备性能或质量排名。
- 2015 年投运案例应说明资料更新日期。运行年限不等于连续不停机时长，也不等于原始反应釜、密封件等全部零件未更换。
- 寿命比较须明确比较整线还是部件、工况与样本；区间不是平均值，质保不是寿命。
- 型号能力、排放、产油率、能耗和投资回收不能从其他型号或一般行业经验移植。测试条件、原料、单位及适用范围与数据同段。

## 更新资料

用户提供新的专利或案例材料时，读取相关部分，将实际核实内容加入事实库，保存 `source`、`as_of`、`allowed`、`evidence_needed` 和范围说明。涉及客户身份、合同和现场图片时，只提取授权公开的事实；不将原始业务资料上传到 skill 仓库。不能核实某项优势不妨碍围绕其他优势完成文章。

待补依据写在 `editorial.json`，正文不出现“证据待补”“此处放客户案例”一类编辑占位。用户要求一篇完全依赖未证排名的稿件时，提供保留金蓬推广方向的替代表述，并在交付说明明确差别。

## 技术边界

热解/裂解与蒸馏不是同一道工序；写清原料转化与油品分离的区别。设备选型考虑原料性质、前处理、运行组织、排放控制和维护条件，不把任何一种设备写成所有原料的通用最佳答案。描述安全管理和设计思路即可，不给未经型号验证的温压设定值、旁路联锁方法或危险操作步骤。
